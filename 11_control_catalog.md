# Занятие 11. Контрольная работа №3. Каталог коллекции

## Цель

Проверить умение реализовывать управление данными, статистическую обработку и сохранение каталога.

## Теория

Каталог хранится в контейнере независимо от экранного представления. При изменении сначала проверяется новая запись, затем заменяется существующая. При загрузке проверяется временный контейнер, после чего обновляется текущий каталог. ID обеспечивает идентификацию при фильтрации.

`QSet` применяется для уникальных категорий, `QHash` — для счётчиков, `QMap` — для упорядоченного отчёта. JSON и двоичный поток требуют проверки структуры и значений.

**Пример 1. Проверка записи перед заменой.** Используется структура `Game` из занятия 9. Функцию разместить вне класса в `.cpp`:

```cpp
static bool validateGame(const Game &g, QString &error)
{
    error.clear();
    if (g.id < 1 || g.id > 1000000) error = "Недопустимый ID";
    else if (g.title.isEmpty() || g.title.size() > 100)
        error = "Название: 1–100 единиц UTF-16";
    else if (g.genre.isEmpty() || g.genre.size() > 50)
        error = "Категория: 1–50 единиц UTF-16";
    else if (g.rating < 0 || g.rating > 10) error = "Оценка: 0–10";
    return error.isEmpty();
}
```

В обработчике после определения индекса по ID создаётся кандидат. Индекс `index` должен находиться в границах `games`; подключить `<QMessageBox>`:

```cpp
Game candidate = games.at(index); // Сохраняется прежний ID.
candidate.title = ui->titleEdit->text().trimmed();
candidate.genre = ui->genreEdit->text().trimmed();
candidate.rating = ui->ratingSpin->value();
candidate.finished = ui->finishedCheck->isChecked();
QString error;
if (!validateGame(candidate, error)) {
    QMessageBox::warning(this, "Ошибка", error);
    return;
}
games[index] = candidate;
```

Проверка уникальности ID при загрузке выполняется отдельно для всего контейнера. После изменения требуется обновление списка и статистики.

**Пример 2. Статистика пустого и непустого каталога.** Подключить `<QHash>`, `<QMap>` и `<QStringList>`:

```cpp
qint64 sum = 0;
QHash<QString, int> counts;
for (const Game &g : games) {
    sum += g.rating;
    ++counts[g.genre];
}
const QString average = games.isEmpty()
    ? QString("Нет данных")
    : QString::number(double(sum) / double(games.size()), 'f', 2);
QMap<QString, int> ordered;
for (auto it = counts.cbegin(); it != counts.cend(); ++it)
    ordered.insert(it.key(), it.value());
QStringList report{QString("Средняя оценка: %1").arg(average)};
for (auto it = ordered.cbegin(); it != ordered.cend(); ++it)
    report.append(QString("%1: %2").arg(it.key()).arg(it.value()));
ui->resultEdit->setPlainText(report.join('\n'));
```

Примеры определяют отдельные операции; файловые функции, выбор записи и обработку отмены следует объединить согласно требованиям задания.

## Задание

Разработать каталог выбранной предметной области: игры, фильмы, книги, настольные игры или учебные курсы. Технические поля: `id`, `title`, `genre`, `rating`, `finished`; подписи интерфейса должны соответствовать предметной области.

| Параметр | Требование |
|---|---|
| Число записей | 0–10000 |
| ID | Целое 1–1000000, уникальное, назначается программой |
| Название | 1–100 единиц UTF-16 после `trimmed()` |
| Категория | 1–50 единиц UTF-16 после `trimmed()` |
| Оценка | Целое 0–10 |
| Статус | `true` или `false`, ввод флажком |
| Поиск | 0–100 единиц UTF-16; без учёта регистра |
| Загружаемый файл | Не более 2097152 байт |

1. Реализовать добавление, изменение с сохранением ID и удаление выбранной записи после подтверждения. Новый ID — максимум текущих ID плюс один; для пустого каталога — 1. При превышении диапазона добавление запрещено.
2. Выполнить поиск по названию. Пустой запрос показывает все записи. Выбор для изменения и удаления определять по ID, а не по номеру строки.
3. Выводить число записей, число категорий, количество записей по категориям и среднюю оценку. Категории различать с учётом регистра. Отчёт выводить в порядке ключей `QMap`. На пустом каталоге исключить деление на ноль.
4. Реализовать сохранение и загрузку JSON и BIN. JSON: объект `schemaVersion: 1`, массив `items` с пятью обязательными полями. BIN: `quint32 0x51474331`, `quint16 1`, `quint32` — число записей; далее `qint32`, `QString`, `QString`, `qint32`, `bool` в порядке полей. Поток: `Qt_6_0`, `BigEndian`.
5. Отклонять неверные типы, дробные ID/оценки, повтор ID, отсутствующие поля и повреждённые файлы. Ошибка ввода или загрузки не изменяет текущий каталог; отмена диалога не считается ошибкой.
6. Подготовить не менее пяти записей, двух категорий и обоих значений статуса. Названия могут повторяться.

**Проверка:** выполнить все операции, включая изменение при фильтре, отмену удаления, сохранение и восстановление обоих форматов, загрузку пустого каталога и отказ при ошибочном файле. После восстановления должны совпасть значения всех полей и порядок записей. Представить набор данных, JSON, BIN и таблицу результатов проверки.

**Представить:** исходные файлы проекта, форму `.ui`, файл сборки и результаты проверки программы.
