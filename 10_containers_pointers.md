# Занятие 10. Контейнеры Qt, ссылки и указатели

## Цель

Освоить управление коллекцией записей и применение последовательных и ассоциативных контейнеров.

## Теория

`QList<T>` хранит последовательность элементов; доступ по индексу требует соблюдения границ. `reserve()` резервирует память, но не создаёт элементы. В Qt 6 `QVector` является псевдонимом `QList`. `QSet` хранит уникальные значения, `QHash` — пары ключ–значение, `QMap` — пары с обходом в порядке ключей. Метод `value()` читает значение без добавления отсутствующего ключа; неконстантный `operator[]` может создать его.

Ссылка `T &` обозначает существующий объект. Указатель `T *` хранит адрес; `&object` получает адрес, `*pointer` обращается к объекту. Разыменование допустимо только для указателя на существующий объект. Изменение копии указателя внутри функции не заменяет указатель вызывающего кода.

Положение записи на экране может отличаться от индекса в контейнере. Для устойчивой идентификации используется ID, сохранённый в `Qt::UserRole`. Дочерние объекты `QObject` удаляются родителем.

**Пример 1. Контейнеры статистики.** Предполагается объявление `Game` из занятия 9 и контейнера `QList<Game> games`. Подключить `<QSet>`, `<QHash>`, `<QMap>`, `<QStringList>`.

```cpp
QSet<QString> categories;
QHash<QString, int> counts;
QMap<QString, int> completed;
for (const Game &g : games) {
    categories.insert(g.genre);
    ++counts[g.genre];
    if (g.finished) ++completed[g.genre];
}
QMap<QString, int> ordered;
for (auto it = counts.cbegin(); it != counts.cend(); ++it)
    ordered.insert(it.key(), it.value());
QStringList rows;
for (auto it = ordered.cbegin(); it != ordered.cend(); ++it) {
    rows.append(QString("%1: всего %2, завершено %3")
        .arg(it.key()).arg(it.value()).arg(completed.value(it.key(), 0)));
}
ui->resultEdit->setPlainText(rows.join('\n'));
```

`value(key, 0)` возвращает ноль для отсутствующей категории, не добавляя её. `QMap` обеспечивает порядок ключей, а не локализованную словарную сортировку.

**Пример 2. Связь списка с данными.** При формировании `QListWidget` сохранить ID; заголовки — `<QListWidgetItem>` и `<QVariant>`:

```cpp
ui->gamesList->clear();
for (const Game &g : games) {
    auto *item = new QListWidgetItem(g.title, ui->gamesList);
    item->setData(Qt::UserRole, g.id);
}
// В обработчике изменения выбранной записи:
const auto *selected = ui->gamesList->currentItem();
if (!selected) return;
const int selectedId = selected->data(Qt::UserRole).toInt();
qsizetype index = -1;
for (qsizetype i = 0; i < games.size(); ++i) {
    if (games.at(i).id == selectedId) { index = i; break; }
}
if (index < 0) return;
// games[index] — запись для изменения; games.removeAt(index) — удаление.
```

Фрагмент заполнения и фрагмент выбора относятся к разным операциям; повторное заполнение списка сбрасывает выделение.

**Пример 3. Ссылка и указатель.** Код выполняется внутри функции:

```cpp
int value = 10;
int &reference = value;
int *pointer = &value;
reference = 20;             // value == 20
if (pointer) *pointer = 30; // value == 30
QList<int> numbers;
numbers.reserve(10);       // size() == 0
numbers.append(value);     // size() == 1
```

Проверка `pointer != nullptr` не гарантирует, что объект ещё существует; время его жизни должно быть известно. Указатели на элементы контейнера не следует сохранять между операциями, способными переместить его данные.

## Подготовка

Средства разработки: C++17, Qt 6.2 или новее, Qt Creator, CMake; тип проекта — Qt Widgets Application, класс главного окна — `MainWindow`. Исходные файлы сохранять в UTF-8. Интерфейс размещать в компоновках. Имена объектов задавать через свойство `objectName`.

Разместить `titleEdit`, `genreEdit`, `ratingSpin`, `finishedCheck`, `gamesList`, `searchEdit`, `resultEdit`; кнопки добавления, изменения, удаления, статистики и файловых операций. Установить диапазон `ratingSpin` 0–10. Использовать структуру и форматы занятия 9.

5. Через `QSet<QString>` определить число категорий, через `QHash<QString, int>` — количество записей каждой категории. Вывести общее количество и среднюю оценку. Для пустого каталога средняя оценка — «Нет данных».

7. Подключить загрузку и сохранение JSON/BIN. После успешной загрузки обновлять интерфейс; при ошибке сохранять текущие данные.

Изменить и удалить запись при действующем фильтре; проверить выбор по ID. Представить краткое пояснение различий значения, ссылки и указателя.
